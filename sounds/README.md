# Sound files

Put your own sounds here, named after the button. Each file replaces that button's placeholder on any device.
Formats: mp3, m4a, wav or ogg (the first one found wins, in that order).

bell, silence, vote, served, eyesclosed, traitors, seer, guardian, eyesopen,
poisoned, saved, drumroll, banished, traitorout, innocent,
housewins, traitorswin, toast, parabens,
heartbeat, thunder, wolf, owl, applause, gong

Example: `bell.mp3`, `eyesclosed.m4a`
A file uploaded on the phone (Edit mode) takes priority over the file here.
